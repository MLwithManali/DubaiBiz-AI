# DubaiBiz AI

**AI-Powered Business Operations & CRM Platform**

DubaiBiz AI is a full-stack SaaS project designed to help UAE businesses manage customer relationships, sales leads, business analytics, and AI-assisted workflows through a centralized platform.

### Planned Features
- Customer Relationship Management (CRM)
- Lead Tracking and Follow-Up Management
- Business Analytics Dashboard
- AI-Powered Customer Support
- Intelligent Lead Classification
- Secure User Authentication and Role-Based Access

### Planned Technology Stack
- **Frontend:** React.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, Prisma ORM
- **AI Integration:** Python, FastAPI, LLM API
- **Development Tools:** Git, GitHub

### Project Status
In Development — October 2026

### Project Goal
Build a practical, scalable, AI-enabled business management platform demonstrating full-stack development, REST API design, database integration, and AI-powered automation.
